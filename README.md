## О проекте

Репозиторий содержит решения **лабораторной работы №1** по дисциплине «Непрерывное интегрирование и сборка программного обеспечения» (ФПМИ БГУ, кафедра ТП).

**Цель работы:** изучение современных технологий контейнеризации.

**Задачи:**

1. Установить средство контейнеризации Docker.
2. Изучить применение и принципы Docker.
3. Изучить создание многоконтейнерных инфраструктур.
4. Исследовать структуру файла Dockerfile и применить для конфигурации контейнеров.
5. Описать подходы для создания Dockerfile при сборке образа.
6. Изучить утилиту Docker Compose и структуру файла `compose.yaml`.
7. Развернуть проект из не менее 3 различных сервисов при помощи Docker Compose.
8. Оформить отчёт в формате Markdown и опубликовать в Git-репозитории.
